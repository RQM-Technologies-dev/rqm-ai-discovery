# RQM AI Discovery

This repository publishes public, quantum-only discovery documentation.
Use only anonymous public service contracts and public research references.
Never add execution, credentials, payment collection, or an MCP proxy to the Space.
Keep catalog payloads unmodified and provenance separate. Never turn a declared
readiness label into independently verified execution or hardware evidence.

Edit content/ and templates/, then run python3 scripts/build.py.
Run python3 -m unittest discover -s tests and python3 scripts/build.py --check
before publishing. Refresh through python3 scripts/refresh.py and review its diff.
No scheduled publication or paid acceptance tests.
